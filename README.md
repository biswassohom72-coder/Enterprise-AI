# 📊 Enterprise GenAI Data Assistant

An intelligent, interactive data analysis web application built for seamless data exploration. This AI-powered assistant allows users to upload datasets (CSV/Excel) and ask complex questions in natural language to instantly generate insights.

## 🚀 Key Features
* **Natural Language Queries:** Ask questions about your data (e.g., "What is the maximum selling price?" or "Which car has the highest mileage?") and get precise answers.
* **Secure API Integration:** Users can securely input their own Google Gemini API key via the UI to process data.
* **Instant Data Preview:** Quickly view the first few rows of your uploaded dataset for context.

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **Core Logic:** Python, Pandas
* **AI & LLM:** LangChain, Google Gemini (ChatGoogleGenerativeAI)
